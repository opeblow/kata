## kata_search_read_terminal  (candidate, v2)

Routine observed in 4 separate conversations: `search_files`, then `read_file`, then `terminal`.

### Why Kata proposed this
- Seen in 4 separate conversations (4 matching runs)
- Held-out fit 100%, confidence 0.87
- By hand it took 3 tool calls, 2.0 model round-trips, ~4190 tokens, 240 ms

### Steps (executed in this order, no model calls in between)
1. `search_files`(path="src", pattern="TODO({pattern})")  [read: `search_files` only reads]
2. `read_file`(path=<step 1.matches.0.path>)  [read: `read_file` only reads]
3. `terminal`(command="wc -l <step 2.path>")  [read: `wc` only reads]

### Permissions
- May call only: read_file, search_files, terminal
- Highest effect: read
- Read-only or local steps; read-only steps may be retried once on error

### Input schema
```json
{
  "type": "object",
  "properties": {
    "pattern": {
      "type": "string",
      "description": "Variable part of `pattern` in step 1."
    }
  },
  "required": [
    "pattern"
  ],
  "additionalProperties": false
}
```
### Output schema
```json
{
  "type": "object",
  "properties": {
    "exit_code": {
      "type": "integer"
    },
    "output": {
      "type": "string"
    }
  },
  "required": [
    "exit_code",
    "output"
  ]
}
```
### Validation (passed)
- [x] compilable_tools: all steps use compilable tools
- [x] recorded_examples: 4 recorded example(s) available
- [x] replay_matches_recorded: 4/4 examples reproduced exactly
- [x] holdout_fit: held-out fit 100% (minimum 90%)
- [x] input_schema: schema accepts recorded inputs and rejects missing ones
- [x] executor_replay: executor reproduced 4 recorded run(s) call-for-call
- [x] failure_handling: injected failure at step 2 stopped the run; later steps skipped
- [x] timeout_handling: a hung step times out, is not re-issued, and stops the run
- [x] output_schema: recorded results match the output schema
- [x] no_secrets: no credentials embedded
- [x] tools_available: all tools available, schemas unchanged
- [x] side_effects: read/local only; runs without extra prompts
